# 需求访谈记录（2026-09-05）

> 访谈方式：AI 以苏格拉底式一次一问、带编号选项，本人作答；结论汇总为 [[项目/缠论分析工具/01-需求规格SPEC|01 需求规格 SPEC]]。本文件为原始记录，供日后追溯"当初为什么这么定"。

## 一、访谈前的可行性评估结论

- 能做，工程上不算高风险；核心链路（包含处理 → 分型 → 笔 → 线段 → 中枢）是确定性算法，几千根 K 线毫秒级。
- 真正的风险不在"写不写得出来"，而在缠论本身没有唯一标准答案（老笔 / 新笔、线段划分、中枢延伸 / 扩展、级别递归与否），以及"当下"结构会重画。
- 其它风险：免费数据源不稳定、港股分钟级历史短、必须前复权、买卖点主观性强。
- 建议不从零造轮子：chan.py（Vespa314）、czsc（waditu）可作参考与验证基准。

本人对上述评估及"A 股 + 港股、≥ 5 分钟级别、K 线周期近似、老笔默认可切新笔、plotly 静态 → Streamlit"的建议全部同意，随后进入访谈。

## 二、访谈问答

**Q1 这个工具最主要的目的是什么？**
选项：1 学习缠论；2 辅助自己的实盘交易；3 量化 / 选股系统基础模块；4 做成产品给别人用。
**答：2。辅助自己的实盘交易：复盘和寻找买卖点，作为决策参考。**

**Q2 主要在什么时候用？**
选项：1 只盘后 / 周末；2 主要盘后，盘中偶尔手动刷新；3 盘中定时自动刷新；4 盘中秒级实时。
**答：2。主要盘后复盘，盘中偶尔手动刷新看一眼，延迟几分钟无所谓。**

**Q3 关注的股票范围有多大？**
选项：1 每次一只手动输入；2 固定自选股池 10~50 只快速切换；3 自选股池 + 每日自动提示信号；4 全市场扫描。
**答：2。固定自选股池（约 10~50 只），快速切换查看。**

**Q4 第一个可用版本缠论要素做到哪一层？**
选项：1 只要笔 / 段 / 中枢；2 + 三类买卖点；3 + MACD 背驰与走势类型；4 全都要且每个买卖点附成立理由。
**答：4。全都要，并且每个买卖点要附"成立理由"的文字说明（边用边学）。**

**Q5 怎么判断工具画得对不对？**
选项：1 以在用的参考软件为基准；2 拿关注的博主的图对比；3 没有基准，靠 AI 自查 + 看图合理；4 用 chan.py / czsc 交叉验证，不一致处解释。
**答：4。用成熟开源实现交叉验证，不一致的地方解释给我听。**

**Q6 交付节奏？**
选项：1 尽快先有能看的，买卖点后续迭代；2 一次交付完整功能；3 分阶段交付，每阶段经看图确认后才进入下一阶段；4 时间无所谓但每阶段要自动化测试和交叉验证报告。
**答：3。分阶段交付，每个阶段必须经我看图确认后才进入下一阶段。**

**Q7 港股分钟级数据的立场？**
选项：1 只用免费源，慢慢积累；2 有券商账号接 OpenAPI；3 愿意付费买数据；4 港股先只做日 / 周线，分钟级第一阶段只做 A 股。
**答：4。港股先只做日线 / 周线，分钟级别第一阶段只做 A 股。**

**Q8 买卖点"成立理由"的形态？**
选项：1 一句话结论；2 结构化判定清单；3 教学式段落含风险提示；4 图上用 1 的简短版，点开看 2 + 3。
**答：4。图上简短版，点开后看详细版。**

**Q9 多级别怎么看？**
选项：1 一次一个级别大图 + 高一级中枢 / 笔端点投影；2 两级别上下并排联动；3 三级别纵向堆叠；4 先做 1，并排后续再说。
**答：4。先做 1，并排联动后续再说。**

**Q10 运行环境？**
选项：1 只在这台 Mac 手动启动；2 Mac 上每天自动拉数据；3 有云服务器 / NAS 常驻；4 先按 1 做，不堵死 3 的路。
**答：4。先按 1 做，不堵死 3 的路。**

**Q11 明确不在本次范围内的（多选）？**
选项：1 自动下单；2 推送提醒；3 回测与胜率统计；4 手机端访问；5 多用户 / 公网部署；6 其他市场；7 交易日志 / 复盘笔记。
**答：1、2、3、6。**（4、5、7 未排除，作为预留方向）

**Q12 买卖点提示的偏向？**
选项：1 宁可多报不漏报；2 宁可少报；3 都标但分"严格成立 / 疑似待确认"两档并说明差在哪；4 只标历史走出来的用于学习。
**答：3。都标，分两档颜色区分，理由里说明差在哪。**

**Q13 代码以后由谁维护？**
选项：1 会 Python，自己改；2 会一点，主要靠 AI 改，要中文注释；3 不写代码只要能用；4 完整开发文档 + 架构说明 + 自动化测试，方便交给别人接手。
**答：4。**

## 三、访谈后的补充问答

**入口怎么设计？**
答复：统一命令 `chan`（ui / plot / pool / update / import / verify）+ Mac 双击启动器；网页首屏为左侧自选股池 + 参数、主区级别切换 + 图 + 买卖点列表 + 详情面板。本人未提出异议。

**自选股池从哪里来？股票数据从哪里来？**
答复：自选股池由本人手动录入或从现有软件导出后导入，工具不替本人选股；数据 A 股 baostock 为主、东方财富补盘中，港股东方财富为主、yfinance 备源，本地 SQLite 缓存增量更新。

**现在的自选股主要在哪个软件？**
**答：主要在东方财富里，也可以直接手动录入，不一定需要导入。**
→ 决定：手动维护为主 + 通用文本批量导入，不做东方财富账号对接。
