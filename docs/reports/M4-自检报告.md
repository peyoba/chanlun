## 关键 bug 修复：watchlist 前导零代码被解析为八进制

PyYAML（YAML 1.1）把 `00700` 解析为八进制整数 448、`002466`→1334、`000001`→1，normalize 后变成错误港股代码。后果：股池显示错乱；数据库被写入 01334.HK / 00001.HK / 00448.HK 的错误数据（真实公司名，因数据源按代码真实拉取）。

处理：`wl.load` 改用 `yaml.BaseLoader`（全部标量保持字符串）；删除数据库中三个错误代码的全部行（klines / stocks / update_log）；补拉 002466.SZ、000001.SZ 真实数据（全量四级别入库成功）。00700.HK 数据本就正确，未动。
