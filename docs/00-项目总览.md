# 缠论分析工具 · 项目总览

> 一句话：输入 A 股 / 港股代码，自动在多级别 K 线图上画出笔、线段、中枢，并给出分档规则满足度、附成立理由的三类买卖点。用于盘后复盘与实盘决策参考，同时边用边学缠论。

**项目代号：** `chanlun`
**本目录：** 文档备份副本。代码库在 `~/Desktop/web/chanlun/`，开发引用以代码库 `docs/` 为准（本地数据缓存是百万行级 SQLite，不进 Obsidian 库）
**运行方式：** 本机 Mac 手动启动，`chan ui` 打开本地网页；架构不堵死服务器常驻部署

## 核心决策速览

- 市场与级别：A 股 5 分 / 30 分 / 日 / 周；港股 日 / 周（港股分钟级本期不做）
- 级别口径：K 线周期近似 + 高一级中枢投影联立（不做严格递归）
- 笔：默认老笔，可切新笔；线段：特征序列法；中枢：笔中枢 + 段中枢
- 买卖点：一 / 二 / 三类，分「严格成立 / 疑似待确认」两档；图上一句话理由，点开看判定清单 + 教学说明
- 正确性基准：自研引擎，用 chan.py / czsc 做交叉验证，差异逐条解释
- 交付：阶段 0 → 4，每阶段经本人看图确认后才进入下一阶段
- 输出路线：plotly 静态 HTML → Streamlit 网页 →（后续）FastAPI + KLineChart
- 自选股池：手动维护 + 通用文本批量导入，不对接任何行情软件账号
- 数据：A 股 baostock 为主、东方财富补盘中；港股东方财富为主、yfinance 备源；本地 SQLite 增量缓存

## 边界

本期包含：A 股四级别 + 港股两级别的笔 / 段 / 中枢 / 走势类型 / 背驰 / 买卖点计算与绘图；自选股池（手动维护 + 文本批量导入）；本地数据缓存与手动增量更新；命令行 + 静态 HTML + Streamlit 网页；开发文档与自动化测试。

本期不包含：自动下单、推送提醒、回测与胜率统计、其他市场、港股分钟级、严格递归级别、多级别并排联动、秒级实时、全市场扫描、行情软件账号对接。手机端 / 公网部署 / 复盘笔记为预留方向，架构上不堵死。
