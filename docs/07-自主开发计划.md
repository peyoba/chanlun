# 自主开发计划（2026-09-05 起）

> 本人指示：AI 连续开发，自己检查确认后直接进入下一步；只在**必须本人决定**的事项上停下来。目标是尽快拿到可用成果。本计划替代 04 实施路线中"每阶段本人看图门禁"的推进方式（见 ADR-016），阶段内容与验收标准仍以 04 为准。

## 长期目标

在本机双击 `启动缠论工具.command` 即可打开网页：选自选股、切级别，看到 K 线上叠加的笔 / 线段 / 中枢 / 买卖点（含规则满足度分档与理由），数据可一键更新。引擎有单元、golden、回放、交叉验证四层测试，文档可交接。

## 自检规则（替代人工门禁）

1. 每个里程碑结束：pytest 全绿 + 对样本集生成图并由 AI 目视检查（截图审阅）+ 写《Mx 自检报告》到 `docs/reports/`。
2. 发现规则口径与 02 文档冲突：以 02 为准；02 本身有歧义时按 chan.py 默认行为取舍，记入 02 验证记录与 05 决策记录，不停下来问。
3. 下列情况**必须停下来问本人**：需要付费 / 账号；数据源全部不可用且无免费替代；02 文档的某条规则实现后明显与缠论原文相悖且无法通过配置两全；需要删除或覆盖本人的文件。
4. 其余一切（依赖选型、阈值初值、样本集"待定"股票的临时替代）AI 自行决定并记录。
