# 缠论规则与实现口径（v0.1）

> **本文件是引擎实现的唯一规则权威源。** 每条规则标注来源（缠中说禅《教你炒股票》108 课的课次）与本项目的取舍；凡是原文有多义的地方都单独标出「取舍」，并在 [[项目/缠论分析工具/05-决策记录|05 决策记录]] 留痕。所有阈值都放在配置文件，不写死在代码里。
> 状态：v0.1 为编码前草案；阶段 1~3 每完成一个模块，须把交叉验证发现的差异回写到本文件对应小节的「验证记录」。

## 0. 术语表（给本人看的最小词汇表）

| 术语 | 含义 |
|---|---|
| 包含关系 | 相邻两根 K 线，一根的高低点完全包住另一根 |
| 分型 | 三根（处理后的）K 线，中间那根最高叫顶分型，最低叫底分型 |
| 笔 | 相邻的一个顶分型和一个底分型的连线，是最小的走势单元 |
| 线段 | 至少三笔构成、有重叠的走势，是笔的上一层 |
| 特征序列 | 判断线段是否结束时用的辅助序列：向上线段取其中的向下笔，反之亦然 |
| 中枢 | 至少三个连续次级别走势重叠的价格区间 |
| ZG / ZD | 中枢上沿 / 下沿（前三段高点的最小值 / 低点的最大值） |
| GG / DD | 中枢存续期间的最高点 / 最低点 |
| 走势类型 | 盘整（一个中枢）或趋势（两个以上同向不重叠中枢） |
| 背驰 | 价格创新高 / 新低但力度（MACD 等）减弱 |
| 一买 / 一卖 | 趋势末端背驰形成的反转点 |
| 二买 / 二卖 | 一买后第一次回调不破一买低点形成的点 |
| 三买 / 三卖 | 离开中枢后回抽不回中枢形成的点 |
| 级别 | 走势结构的"尺寸"；本项目用 K 线周期近似（5 分 / 30 分 / 日 / 周） |
| 次级别 | 低一个级别（日线的次级别按 30 分钟近似） |
| 已确认 / 未确认 | 结构是否还可能随新 K 线改变 |

## 1. K 线包含处理

**来源**：第 62 课、第 65 课。

**规则**
1. 相邻 K 线 K1、K2，若 `h1 ≥ h2 且 l1 ≤ l2` 或 `h1 ≤ h2 且 l1 ≥ l2`，判定为包含关系（完全相等也算）。
2. 合并方向由"被包含前那根合并 K 线相对它前一根"决定：高点更高为向上，低点更低为向下。
3. 向上合并：`high = max(h1, h2)`，`low = max(l1, l2)`；向下合并：`high = min(h1, h2)`，`low = min(l1, l2)`。
4. 合并后的 K 线记录原始 K 线索引区间 `[raw_start, raw_end]`，时间戳取区间末根。此区间用于新笔计数、MACD 面积累计和绘图定位。
5. 合并可以连锁：新合并出的 K 线继续与下一根比较。

**取舍**
- 序列开头若前两根就有包含关系，丢弃到第一对无包含的相邻 K 线为止（只影响历史最前端，不影响当下）。
- 合并 K 线只用于结构计算；图上仍画原始 K 线，结构线画在合并 K 线对应的原始位置上。
- open / close 不参与合并逻辑。

## 2. 分型

**来源**：第 62 课。

**规则**
- 顶分型：合并 K 线 `K[i-1], K[i], K[i+1]`，`h[i]` 为三者最高且 `l[i]` 为三者最高。
- 底分型：`l[i]` 为三者最低且 `h[i]` 为三者最低。
- 因为已做包含处理，相邻合并 K 线不存在包含关系，所以只要 `h[i]` 最高就必然 `l[i]` 最高，实现时只需比较一端。
- 分型记录：类型、位置 i、极值价（顶取 `h[i]`，底取 `l[i]`）、三根 K 线整体的最高 / 最低（供笔的价格条件检查）。

## 3. 笔

**来源**：第 62 课（老笔原始定义）、第 65 / 77 课，以及缠师后期博客回复中的修正（新笔）。

### 3.1 共同前提
1. 笔连接相邻的一顶一底：顶 → 底为向下笔，底 → 顶为向上笔；顶底必须交替。
2. 同类型分型连续出现时取更极端者（顶取更高、底取更低），即"笔延伸"。
3. **价格条件**（分型间隔检查，对齐 chan.py 的 `bi_fx_check`）：
   - `strict`（默认）：向下笔要求顶分型的最高点高于底分型三根 K 线的最高点，且底分型的最低点低于顶分型三根 K 线的最低点；向上笔对称。
   - `loss`：只要求顶分型最高点高于底分型中间 K 线高点、底分型最低点低于顶分型中间 K 线低点。
   - `half` / `totally`：预留，语义与 chan.py 对齐。

### 3.2 老笔（默认）
- 顶 K 与底 K 之间至少有 1 根独立合并 K 线（不属于任一分型）。
- 等价表述：顶 K 与底 K 的合并索引差 ≥ 4，即顶到底（含两端）至少 5 根合并 K 线。

### 3.3 新笔（可切换）
- 两个分型不共用合并 K 线（合并索引差 ≥ 3，允许紧挨）。
- 顶 K 与底 K 之间（不含两端）的**原始 K 线**数量 ≥ 3。

**取舍**：新笔的"原始 K 线 ≥ 3"按缠师原话执行；部分实现改为"顶到底含两端 ≥ 4 根合并 K 线"，差异在阶段 1 交叉验证时逐例说明。

### 3.4 构造算法要点
1. 按顺序遍历分型，维护"当前候选笔"（起点 S、终点 E）。
2. 新分型与 E 同类型：更极端则更新 E（延伸），否则忽略。
3. 新分型与 E 异类型：检查 E → 新分型是否满足 3.1 ~ 3.3。
   - 满足：当前候选笔确认，新分型成为下一候选笔的终点。
   - 不满足：忽略该分型；但若它比 S 更极端（例如向上候选笔期间出现低于 S 的底），当前候选笔作废，S 回退为该分型（等价于前一笔延伸）。
4. 序列末尾的候选笔标记 `confirmed = false`。

### 3.5 已确认口径与确认时间
- 一笔"已确认" = 它之后已经有一笔成立的反向笔。最后一笔永远是未确认的。
- **确认时间 `confirmed_at`**：使该笔满足上述条件的那根合并 K 线对应的原始 K 线时间戳（即反向笔成立的时刻），与笔端点的发生时间分开记录，图上悬停同时显示"端点出现于 / 确认于"。
- **潜在漏洞（开放问题 6）**：3.4 允许候选笔作废并回退为前一笔延伸，这意味着"之后有一笔成立的反向笔"仍可能被延伸改掉终点。备选收紧口径：已确认 = 之后的反向笔本身也已确认（确认滞后两笔）。由阶段 1 的逐根回放测试用实际数据裁决，回放测试断言"已确认笔的端点永不变化"是阶段 1 的核心验收项而非附加项。

## 4. 线段

**来源**：第 65 课（定义）、第 67 课（特征序列与两种情况）、第 71 / 77 课（补充说明）。

### 4.1 定义
- 至少 3 笔，且前三笔有重叠区间（第 1 笔与第 3 笔的价格区间有交集）。
- 线段方向 = 首笔方向；线段包含的笔数必为奇数。

### 4.2 特征序列
- 向上线段：以其中每一向下笔为元素，元素区间 `[low, high]`；向下线段：以向上笔为元素。
- 特征序列元素之间做包含处理，合并规则与 K 线相同。
- **原文规定**：构成分型的第一元素与第二元素之间**不做**包含处理；第二元素及之后按方向合并。

### 4.3 结束判定
- 向上线段结束 ⇔ 特征序列出现顶分型；向下线段结束 ⇔ 出现底分型。分型中间元素的起点即线段终点。
- **第一种情况（无缺口）**：分型第一元素与第二元素的区间有重叠 → 线段就地结束，无需等待。
- **第二种情况（有缺口）**：第一、二元素之间有缺口（对向上线段：第二元素的 low > 第一元素的 high）→ 需要从分型顶点开始的反向线段，其特征序列也形成相应分型（对向上线段的结束，需要新向下线段的特征序列出现底分型）才确认结束；确认前若价格突破分型顶点（向上线段创新高），分型作废，原线段延续。

### 4.4 已确认口径
- 已被第一种情况结束，或第二种情况已获反向确认的线段 = 已确认。
- 最后一段，以及处于第二种情况"等待确认"状态的线段 = 未确认。

**取舍**
- 只实现标准特征序列法；chan.py 另有 `1+1 终结`、`线段破坏` 等算法，本项目只保留配置位不实现。
- 序列起点前不足 3 笔的部分不成段。

**验证记录**：（阶段 2 填写）

## 5. 中枢

**来源**：第 17 课（定义）、第 18 / 20 课（延伸、扩展、升级）、第 21 课。

### 5.1 定义与区间
- 至少三个连续次级别走势重叠的部分。本期次级别用"笔"（笔中枢）或"线段"（段中枢）近似。
- `ZG = min(前三元素高点)`，`ZD = max(前三元素低点)`；须 `ZG > ZD` 才成立。
- `GG / DD` = 中枢存续期间（含延伸）所有元素的最高 / 最低点。

### 5.2 构造约定
- 进入段：中枢首元素之前的一段；离开段：中枢最后元素之后、离开且不再返回的一段。
- 中枢首元素方向与进入段相反（进入段向上 → 中枢从向下元素开始）。
- 笔中枢不跨线段：只在其所属线段内部构造；段中枢在线段序列上构造。
- **交付顺序说明**：线段在阶段 2 才实现，因此阶段 1 的笔中枢**暂不加"不跨线段"约束**，图上标注"笔中枢（初版，未按线段切分）"；阶段 2 加入约束后重跑 golden 测试，差异作为阶段 2 验收包的一部分逐条说明。

### 5.3 延伸与结束
- 延伸：后续元素与 `[ZD, ZG]` 有交集则并入中枢（ZG / ZD 不变，GG / DD 更新，延伸计数 +1）。
- 结束：出现一个元素完全位于 `[ZD, ZG]` 之外（离开），且随后一元素回抽未进入区间 → 中枢结束，此回抽点即第三类买卖点候选；若回抽重新进入区间 → 视为延伸，中枢继续。

### 5.4 升级与扩展（本期只标记不合并）
- 延伸达 9 段及以上：标记"疑似升级"。
- 相邻两个同级中枢区间重叠：标记"疑似扩展"。

### 5.5 已确认口径
- 区间确认：前三元素均已确认（ZG / ZD 不再变化）。
- 结束确认：离开段之后的回抽段已确认且未进入区间。

**取舍**：与 chan.py `zs_algo=normal` 对齐（首元素方向、不跨段）；`over_seg` 模式不实现。

**验证记录**：（阶段 2 填写）

## 6. 走势类型

**来源**：第 17 课。

- 盘整：一段走势只含一个中枢。
- 趋势：至少两个同向且不重叠的中枢——上涨趋势要求后一中枢 `ZD` > 前一中枢 `ZG`；下跌趋势要求后一中枢 `ZG` < 前一中枢 `ZD`。
- 本期：按段中枢序列标注最近走势类型；笔中枢序列用于笔级别提示。

## 7. 背驰

**来源**：第 24 / 27 课（背驰与 MACD 辅助）、第 37 课、第 43 课。

### 7.1 定义
- 趋势背驰：趋势中最后一个中枢的离开段 c 与该中枢的进入段 a 比较力度（a、c 之间必须有中枢 B）；c 创出新高 / 新低但力度弱于 a → 背驰。
- 盘整背驰：单中枢情形下，离开段力度弱于进入段。

### 7.2 力度指标（可配置）
- MACD 柱面积（默认）：段起止对应原始 K 线区间内同向 MACD 柱绝对值之和。
- DIF 峰值：段内 DIF 极值的绝对值。
- 价幅 / 时间斜率：备用。
- MACD 参数 (12, 26, 9)，在本级别 K 线上计算。

### 7.3 两档判定
- 严格：面积与 DIF 峰值两项同时背驰，且 a、c 之间 MACD 黄白线回抽零轴（`|DIF| ≤ zero_band`，带宽阈值阶段 3 标定）。
- 疑似：仅一项背驰，或未回抽零轴。

**验证记录**：（阶段 3 填写）

## 8. 买卖点

**来源**：第 17 课（三类买卖点定义）、第 21 课、第 24 课。

### 8.1 一买 / 一卖
- 定义：下跌趋势（≥ 2 个下跌中枢）中最后离开段出现趋势背驰，背驰段低点为一买；一卖对称。
- 严格：趋势成立 + 严格背驰。
- 疑似：单中枢的盘整背驰，或背驰为疑似档。

### 8.2 二买 / 二卖
- 定义：一买之后第一次次级别上涨结束后的回调低点不低于一买低点。
- 次级别回调用低一级级别的笔近似；5 分钟级别没有低一级，用本级别笔代替。次级别验证**仅用于二买 / 二卖**，三买不做次级别验证（见 8.3 与第 9 节）。
- 严格：一买为严格档，回调为低一级级别的完整一笔以上且低点 > 一买低点。
- 疑似：一买为疑似档，或次级别无法验证；第二次及以后的回调标"类二买"并归疑似档。

### 8.3 三买 / 三卖
- 定义：中枢向上离开段之后第一次回抽的低点 > ZG（不回中枢）。
- 严格：段中枢 + 离开段为线段 + 回抽为本级别已确认的一笔。
- 疑似：笔中枢的三买，或回抽尚未确认（当下候选）。

### 8.4 通用约定
- 同一位置多重信号（如二买同时是三买）合并为一个标记，理由中列出全部。
- 同一中枢 / 趋势内同类买卖点只保留首次成立的一个，后续同类标"类 X 买"。
- 买卖点"已确认" = 它依赖的笔 / 段 / 中枢 / 背驰全部已确认；否则为"当下候选"。

**验证记录**：（阶段 3 填写）

## 9. 级别与联立

- 级别集合：A 股 `5m / 30m / D / W`，港股 `D / W`；一律 K 线周期近似。
- 高一级投影：当前级别图上叠加高一级（5m ← 30m，30m ← D，D ← W）的中枢区间（时间轴按高一级元素起止映射）和笔端点。
- 次级别验证：**只针对二买 / 二卖**的"次级别回调"取低一级级别；无低一级数据时用本级别笔并归疑似档。三买 / 三卖的严格档以 8.3 的本级别条件为准，不依赖低一级数据（原文第 17 课的三买定义即本级别回抽不回中枢；港股无分钟线，若要求次级别验证则港股永远无严格三买，不合理）。
- 港股无分钟级，日线二买 / 二卖的次级别验证一律归疑似档并在理由中说明；三买不受影响。

## 10. 已确认 / 未确认汇总

所有结构对象同时记录 **发生时间**（端点 / 极值所在 K 线）与 **确认时间 `confirmed_at`**（满足已确认条件的那根 K 线），两者必须分开：低点出现在周一、周四才确认，历史图不得暗示周一即可识别。

| 结构 | 已确认条件 | 图上表现 |
|---|---|---|
| 笔 | 之后已有成立的反向笔（见 3.5 开放问题 6） | 实线 / 虚线 |
| 线段 | 已被特征序列分型结束（第一种）或已获反向确认（第二种） | 实线 / 虚线 |
| 中枢区间 | 前三元素已确认 | 实框 / 虚框 |
| 中枢结束 | 离开后回抽段已确认且未入区间 | 框右边界实 / 虚 |
| 背驰 | 比较的两段均已确认 | — |
| 买卖点 | 依赖结构全部已确认 | 实心 / 空心标记 |

## 11. 理由文本规范

### 11.1 简短版（图上悬停 / 列表）
一句话，格式：`类型(级别种类, 档位)：关键条件 + 关键数值`。示例：
- `三买(段级, 严格)：离开中枢[1580, 1620]后回抽低点 1634 未回中枢`
- `一买(疑似)：单中枢盘整背驰，MACD 面积 12.3 < 18.7，DIF 未回零轴`

### 11.2 详细版（点开面板）
1. **判定清单**：逐条列出该类买卖点的全部条件，每条给出 通过 / 未通过 / 勉强 及数值。
2. **教学说明**：先讲概念（该类买卖点为什么成立、缠师原文课次），再套本例数据。
3. **薄弱环节与风险**：明确指出哪些条件是勉强满足的、哪些结构尚未确认、如果后续走势如何演变会被否定。

文案模板集中在 `render/explain.py`，概念解释复用本文件术语表。

## 12. 与 chan.py 的对照配置（阶段 1 核对参数名与语义）

| 本项目配置 | chan.py 拟对应 | 备注 |
|---|---|---|
| `bi.mode = old` | `bi_strict = True` | 老笔 |
| `bi.mode = new` | `bi_strict = False` | 新笔口径需核对 |
| `bi.fx_check = strict` | `bi_fx_check = "strict"` | 价格条件 |
| `seg.algo = feature_seq` | `seg_algo = "chan"` | 特征序列 |
| `zs.bi_zs_cross_seg = false` | `zs_algo = "normal"` | 不跨段 |
| 不合并中枢 | `zs_combine = False` | |
| `divergence.metrics = [area, dif_peak]` | `macd_algo = "area"` / `"peak"` 分别跑两次 | |
| 买卖点类型 | `bs_type = "1,2,3"` | 类二买等对应 `2s / 3a / 3b` 需核对 |

交叉验证脚本只比较结构端点（笔 / 段端点时间与价格、中枢 ZG / ZD / 起止），买卖点只作参考对照不设阈值。

**基准固定**：chan.py 固定到指定 commit（阶段 1 开工时写入 `tests/crossval/BASELINE.md`：仓库地址、commit hash、配置文件、样本数据快照）；一致率只说明两套实现接近，**不单独证明规则正确或交易有效**，须配合单元测试中的手工边界案例。

## 13. 开放问题（待阶段验证后关闭）

1. 新笔的原始 K 线计数口径（≥ 3 根不含两端 vs 其他实现）。
2. 特征序列包含处理在分型左侧是否完全不做，以及缺口判定用元素区间还是用笔端点。
3. 中枢首元素方向约定在"进入段本身就是中枢一部分"的边界情形下如何处理。
4. 二买"次级别"用低一级笔近似是否足够，还是需要低一级线段。
5. 严格 / 疑似各项阈值（零轴带宽、面积比阈值）的标定方法。
6. 笔的"已确认"口径是否需收紧为"后续反向笔本身也已确认"，以保证已确认笔永不重画（阶段 1 回放测试裁决）。
7. 中枢结束规则中"回抽重新进入区间视为延伸"会撤回已提示的三买候选，阶段 2 对照 chan.py `normal` 模式核对并决定是否保留候选记录。
